# Gentle Mesh 🌐

> Transporte Distribuido y Ejecución de Subagentes Remotos para Pi & Gentle AI.

`gentle-mesh` desacopla el cómputo de la terminal local, permitiendo que `gentle-pi` delegue tareas complejas a nodos remotos (servidores dedicados, clusters GPU, edge) mediante un binario único en Go, API REST y streaming reactivo SSE.
