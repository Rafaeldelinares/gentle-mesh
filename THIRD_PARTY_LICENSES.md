# Third-Party Licenses

Licencias de las dependencias de terceros de **Gentle Mesh**, tanto directas como
indirectas, tal como se declaran en `go.mod`.

## Método de generación

1. **Inventario de licencias:** `go-licenses report ./...` con **go-licenses v2.0.1**
   (`github.com/google/go-licenses/v2`, release oficial).
2. **Texto íntegro:** `go-licenses save ./... --save_path=<dir>`, que extrae el fichero
   `LICENSE` real de cada módulo.
3. **Excepción:** `go-licenses` no recorre las dependencias que solo aportan código no-Go
   (avisa con `W1005`); para `github.com/mattn/go-isatty` y `github.com/ncruces/go-strftime`
   el texto se toma **verbatim** del `LICENSE` del *module cache* de Go.

Ningún texto de este archivo fue redactado ni modificado a mano.
